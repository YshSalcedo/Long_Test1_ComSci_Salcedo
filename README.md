# Long_Test1_ComSci_Salcedo

## Description

This program calculates the number of boxes full of notebooks and notebooks that do not fill a whole box which are sent in a loose pack.

## How to Run

1. Open the program file in VS Code, Replit, or Google Colab.

2. Run the program.

3. Enter the "Total Number of Notebooks:"

4. Enter "How many notebooks fit in one box:"

5. Check how many full boxes and how many loose notebooks are displayed on the screen.

## Input Needed

-Total Number of Notebooks

-How many notebooks fit in one box

## Sample Output
Total Number of Notebooks: 123 

How many notebooks fit in one box: 32

There are 3 full boxes

There are 27 loose notebooks
